# Macropad-Hack-Club-Hack-Life-Week-5
Macropad for hack club

For this week's project, I made a Macropad with 4 keys and a rotary encoder powered by a XIAO RP2040. I used KiCad to design the PCB, Onshape to design the case, and python for the firmware. I started off by adding the necessary components in the schematic editor found in KiCad. After I sketched out the schematic, I assigned each feature with their own footprint and updated all of this into the PCB editor. In the PCB editor, I adjusted the layout of the board and wired the pads together by following the "rat nest." I utilized both the front and back part of the board in order to finish the wiring. After I was done with the PCB, I exported it into a .step file where I created the case based off of the dimensions of the PCB. I went through a lot of trial and error before I came up with a case that was both visually appealing, and delivered quality performance. Now with everything in place, I worked on the firmware. There wasn't much I could do with the firmware without my parts, so I had to wait on that but this week's assignment technically is complete.
